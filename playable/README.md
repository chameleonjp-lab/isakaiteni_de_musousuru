# 王都からの脱出　ブラウザ版

玉座の間から始まる探索ゲーム。部屋を選んで移動し、部屋の人物や仕掛けを調べる。場面の3D表示を左右にドラッグすると視点が変わる。首輪を外し、その後に一度も発見されず、王家の通路の境石を内から外へ越えれば脱出に成功する。

最短20行程と任意300場面の本文は、[シナリオ資料](../docs/scenario/README.md)と同じJSONから組み込む。プレイヤーの選択と手帳を使って成立を判定し、任意場面は条件を満たしたときに現れる。分岐の両方を見るには、選ぶ前から別の周回で試す場面がある。

謁見の玉座と人物モデルは、指定のDriveにある[試遊版](https://drive.google.com/file/d/1MZAaQGoNirY7m5cFIuL5zkXc1f0TJIyn/view)の描画コードを引き継いだ。探索室は区域ごとの照明と、雨量計・肖像・星暦盤などの仕掛けに合わせた3D表示を加えた。部屋間は隣室を選んで移る。会話本文や選択肢は、3Dを描画できない環境でも操作できる。

## HTMLを作る

リポジトリのルートで実行する。

```sh
python -B playable/build.py /tmp/castle_escape.html
node playable/verify.cjs
python -B scripts/verify_scenario.py
```

ビルドは試遊版と同じThree.js r128を読み込み、固定したハッシュと照合する。手元に同じThree.jsファイルがある場合は、ビルドに `--three` とファイルの場所を指定できる。完成したHTMLにはシナリオ、3D用コード、表示、効果音が入る。ブラウザで開くと、一つのファイルで遊べる。ゲームの途中経過は保存を許可するブラウザでは端末に残る。

任意場面や部屋を追加するときは、シナリオ資料のデータを編集してから再ビルドする。本文と条件は原本を基準にし、各仕掛けで表示する複数の選択肢は `puzzles.js` で管理する。
