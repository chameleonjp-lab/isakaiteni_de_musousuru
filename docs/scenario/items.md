# 重要な道具と情報の行き先

[資料の目次](README.md) ・ [最短行程](main-route.md) ・ [城内地図](castle.md) ・ [人物](cast.md) ・ [重要品](items.md)

見当をつける場所、現物を取り出す場所、実際に使う場所をたどれる。番号を押すと、その場面の行動・前提・結果に移動する。任意の宝箱20個は下段にまとめた。

<a id="i01"></a>

### I01　綴じ穴のある備品図

**入手**　[M03 客札で綴じ直した備品図を借りる](main-route.md#m03)

**隠し場所**　西資料室の移転品棚。客札の絵と同じ綴じの束。

**入手の条件**　司書は客札と交換で貸し出す。現物を東の洗濯係と北の陶工に見せる。

**使う場面**　[M04 図の布印に合う燕尾の布札を、干し台の裏から引き出す](main-route.md#m04) ／ [M05 備品図の欠けた縁に合う釉薬見本を型から外す](main-route.md#m05) ／ [M11 冬客間の背くらべ柱に、備品図の綴じ穴を重ねる](main-route.md#m11)

貸出中は手元に保持。地図の写しだけが記憶に残った場合も、貸出記録は復元時点に従う。

<a id="i02"></a>

### I02　燕尾の布札

**入手**　[M04 図の布印に合う燕尾の布札を、干し台の裏から引き出す](main-route.md#m04)

**隠し場所**　東の干し台の裏。服の山の表からは普通の裾に見える。

**入手の条件**　備品図にある布印を持参した客に、洗濯係が裏を開ける。紙に写した燕では箱に入らない。

**使う場面**　[M06 布札と釉板を合わせ、返納箱の受け口に差す](main-route.md#m06) ／ [M09 燕尾の布札で東廊下の木箱の布留めをほどく](main-route.md#m09)

留め具を開けると札は手元へ戻り、二つの使い道を好きな順で試せる。

<a id="i03"></a>

### I03　三溝の釉板

**入手**　[M05 備品図の欠けた縁に合う釉薬見本を型から外す](main-route.md#m05)

**隠し場所**　北の窯見本室。色が似た型の中の、縁の欠けた一枚。

**入手の条件**　貸出図の波形に合う見本だけ、陶工が持ち出しを認める。

**使う場面**　[M06 布札と釉板を合わせ、返納箱の受け口に差す](main-route.md#m06)

返納箱は本物の厚さと溝で動く。誤った型合わせでは破損しない。

<a id="i04"></a>

### I04　中空の調律棒

**入手**　[M06 布札と釉板を合わせ、返納箱の受け口に差す](main-route.md#m06)

**隠し場所**　南返納庫。豪華な櫃の隣にある浅い返納箱の二重底。

**入手の条件**　西で知った保管制度を使い、東の布札と北の釉板を重ねる。

**使う場面**　[M08 救護札の窓が示す左脚の切れ目に調律棒を差す](main-route.md#m08)

水を抜くと棒が押し返される。鍵の代用品にはならない。

<a id="i05"></a>

### I05　透明な救護札

**入手**　[M07 首輪の印に合う救護札を記録棚から引く](main-route.md#m07)

**隠し場所**　北施療院。現に装着している輪と同じ印の記録棚。

**入手の条件**　装着した輪を見せて札を借りる。札には鳥自身の左脚の閉水目盛りを合わせる窓がある。

**使う場面**　[M08 救護札の窓が示す左脚の切れ目に調律棒を差す](main-route.md#m08)

庭の台座に差し込むと窓が棒を通す位置を固定する。目盛りを暗記しても札の厚みが要る。

<a id="i06"></a>

### I06　首輪の白鍵

**入手**　[M08 救護札の窓が示す左脚の切れ目に調律棒を差す](main-route.md#m08)

**隠し場所**　中庭の雨量計。左脚内の乾いた筒からくちばしを経て、植木鉢型の受け皿に落ちる。

**入手の条件**　南で得た棒と北の救護札を同時に使う。療術師は医務手順だけ、庭師は水路だけを知る。

**使う場面**　[M17 扉を閉じた無音祈祷室で白鍵を回す](main-route.md#m17)

持ち歩ける。解除後は外れた輪と一緒に手元に残る。

<a id="i07"></a>

### I07　隠密のマント

**入手**　[M09 燕尾の布札で東廊下の木箱の布留めをほどく](main-route.md#m09)

**隠し場所**　東廊下の星箱の底。舞台衣装の裏地に紛れている。

**入手の条件**　東の干し台で得た燕尾の布札が箱の留めに合う。

**使う場面**　[M10 マントを使って織物回廊の裏見台を渡る](main-route.md#m10)

一回十秒。やり直し時に復元。王家の奉納灯は布の下の影も写す。

<a id="i08"></a>

### I08　王家の透かし帯

**入手**　[M10 マントを使って織物回廊の裏見台を渡る](main-route.md#m10)

**隠し場所**　西の織物回廊。客席から見えない、舞台裏の台の縁。

**入手の条件**　東のマントで裏見台に渡ったところで、窓の逆光が二つの模様を照らす。

**使う場面**　[M12 透かし帯と影板を星暦盤の冬至の窓に重ねる](main-route.md#m12)

自動で手元に掛かる。ほかの場所で見た模様の写しでは帯の切り欠きを再現できない。

<a id="i09"></a>

### I09　伏せ舟の影板

**入手**　[M11 冬客間の背くらべ柱に、備品図の綴じ穴を重ねる](main-route.md#m11)

**隠し場所**　南の冬客間。王女の幼少期の背丈にある柱の内側。

**入手の条件**　西資料室の備品図の穴を柱に合わせて、薄板の押さえを外す。

**使う場面**　[M12 透かし帯と影板を星暦盤の冬至の窓に重ねる](main-route.md#m12)

帯は別棟で得る。どちらを先に見つけても保管できる。

<a id="i10"></a>

### I10　王女の星暦頁

**入手**　[M12 透かし帯と影板を星暦盤の冬至の窓に重ねる](main-route.md#m12)

**隠し場所**　北の星暦室。誰でも見る暦盤の冬至の窓の内側に挟まっている。

**入手の条件**　西の透かし帯と南の影板を重ねる。空席、欠け月、伏せた舟の向きが揃う。

**使う場面**　[M13 星暦頁の穴を、鳩舎の二羽彫りの筒の留めに通す](main-route.md#m13) ／ [M14 星暦頁を挟んだ肖像の額に、覗き錘を座らせる](main-route.md#m14)

頁の穴は東の返書筒の留めにも合う。使っても消えない。

<a id="i11"></a>

### I11　覗き錘

**入手**　[M13 星暦頁の穴を、鳩舎の二羽彫りの筒の留めに通す](main-route.md#m13)

**隠し場所**　東の鳩舎。本物の巣でなく二羽彫りの王女専用返書筒の奥。

**入手の条件**　星暦頁が筒の留めを外す。重心をずらした卵形で、底にレンズがある。

**使う場面**　[M14 星暦頁を挟んだ肖像の額に、覗き錘を座らせる](main-route.md#m14) ／ [M19 冠なき像の背の空の巣に、覗き錘を戻す](main-route.md#m19)

肖像を読んだ後は取り外して返る。王家の像に載せた時だけ設置済みになる。

<a id="i12"></a>

### I12　王女の私筆の控え

**入手**　[M14 星暦頁を挟んだ肖像の額に、覗き錘を座らせる](main-route.md#m14)

**隠し場所**　西の肖像修復室。顔料の下の文字は通常の光では断片しか出ない。

**入手の条件**　星暦頁を額に挟み、覗き錘を載せて、首輪の翻訳が残るうちに全図を自筆で写す。

**使う場面**　[M16 香支度室で、巡回環の空番に香車の返納を予約する](main-route.md#m16) ／ [M18 空番の切れ目で、白百合が続く壁際を渡る](main-route.md#m18) ／ [M19 冠なき像の背の空の巣に、覗き錘を戻す](main-route.md#m19)

翻訳が切れても自分の言葉と絵は読める。絵師に内容は伝えない。

<a id="i13"></a>

### I13　巡回環

**入手**　[M15 鐘番室の当番盤から、客用の巡回環を借りる](main-route.md#m15)

**隠し場所**　南鐘番室。勤務盤で客の荷に貸し出す現行品。

**入手の条件**　鐘の音を覚えるだけでは予約できない。現行の欠け歯が香車に合う。

**使う場面**　[M16 香支度室で、巡回環の空番に香車の返納を予約する](main-route.md#m16) ／ [M18 空番の切れ目で、白百合が続く壁際を渡る](main-route.md#m18)

予約後に環は戻る。手元の切れ目で白礼拝廊の空番を読める。
