# 重要な道具と情報の行き先

[資料の目次](README.md) ・ [最短行程](main-route.md) ・ [城内地図](castle.md) ・ [人物](cast.md) ・ [重要品](items.md)

見当をつける場所、現物を取り出す場所、実際に使う場所をたどれる。番号を押すと、その場面の行動・前提・結果に移動する。任意の宝箱20個は下段にまとめた。

<a id="i01"></a>

### I01　綴じ穴のある備品図

**入手**　[M03 客札を見せて、綴じ直した備品図を借りる](main-route.md#m03)

**隠し場所**　西資料室の移転品棚。客札の絵と同じ綴じの束。

**入手の条件**　司書は客札と交換で貸し出す。現物を東の洗濯係と北の陶工に見せる。

**使う場面**　[M04 図の印と同じ布札を、干し台の裏から取る](main-route.md#m04) ／ [M05 波形の縁と裏に三本の溝がある見本を外す](main-route.md#m05) ／ [M11 柱の低い位置にある二つの穴に備品図を重ねる](main-route.md#m11)

貸出中は手元に保持。地図の写しだけが記憶に残った場合も、貸出記録は復元時点に従う。

<a id="i02"></a>

### I02　燕尾の布札

**入手**　[M04 図の印と同じ布札を、干し台の裏から取る](main-route.md#m04)

**隠し場所**　東の干し台の裏。服の山の表からは普通の裾に見える。

**入手の条件**　備品図にある布印を持参した客に、洗濯係が裏を開ける。紙に写した燕では箱に入らない。

**使う場面**　[M06 布札と釉板を返納箱の左右の溝に合わせる](main-route.md#m06) ／ [M09 燕尾の布札を東廊下の星箱の留め具に通す](main-route.md#m09)

留め具を開けると札は手元へ戻り、二つの使い道を好きな順で試せる。

<a id="i03"></a>

### I03　三溝の釉板

**入手**　[M05 波形の縁と裏に三本の溝がある見本を外す](main-route.md#m05)

**隠し場所**　北の窯見本室。色が似た型の中の、縁の欠けた一枚。

**入手の条件**　貸出図の波形に合う見本だけ、陶工が持ち出しを認める。

**使う場面**　[M06 布札と釉板を返納箱の左右の溝に合わせる](main-route.md#m06)

返納箱は本物の厚さと溝で動く。誤った型合わせでは破損しない。

<a id="i04"></a>

### I04　中空の調律棒

**入手**　[M06 布札と釉板を返納箱の左右の溝に合わせる](main-route.md#m06)

**隠し場所**　南返納庫。豪華な櫃の隣にある浅い返納箱の二重底。

**入手の条件**　西で知った保管制度を使い、東の布札と北の釉板を重ねる。

**使う場面**　[M08 救護札をはめ、鷺の左脚に調律棒を通す](main-route.md#m08)

水を抜くと棒が押し返される。鍵の代用品にはならない。

<a id="i05"></a>

### I05　透明な救護札

**入手**　[M07 首輪と同じ印の救護札を借りる](main-route.md#m07)

**隠し場所**　北施療院。現に装着している輪と同じ印の記録棚。

**入手の条件**　装着した輪を見せて札を借りる。札には鳥自身の左脚の閉水目盛りを合わせる窓がある。

**使う場面**　[M08 救護札をはめ、鷺の左脚に調律棒を通す](main-route.md#m08)

庭の台座に差し込むと窓が棒を通す位置を固定する。目盛りを暗記しても札の厚みが要る。

<a id="i06"></a>

### I06　首輪の白鍵

**入手**　[M08 救護札をはめ、鷺の左脚に調律棒を通す](main-route.md#m08)

**隠し場所**　中庭の雨量計。左脚内の乾いた筒からくちばしを経て、植木鉢型の受け皿に落ちる。

**入手の条件**　南で得た棒と北の救護札を同時に使う。療術師は医務手順だけ、庭師は水路だけを知る。

**使う場面**　[M17 扉を閉じてから、白鍵で首輪を外す](main-route.md#m17)

持ち歩ける。解除後は外れた輪と一緒に手元に残る。

<a id="i07"></a>

### I07　隠密のマント

**入手**　[M09 燕尾の布札を東廊下の星箱の留め具に通す](main-route.md#m09)

**隠し場所**　東廊下の星箱の底。舞台衣装の裏地に紛れている。

**入手の条件**　東の干し台で得た燕尾の布札が箱の留めに合う。

**使う場面**　[M10 マントで姿を隠し、白い線に沿って渡る](main-route.md#m10)

一回十秒。やり直し時に復元。王家の奉納灯は布の下の影も写す。

<a id="i08"></a>

### I08　王家の透かし帯

**入手**　[M10 マントで姿を隠し、白い線に沿って渡る](main-route.md#m10)

**隠し場所**　西の織物回廊。客席から見えない、舞台裏の台の縁。

**入手の条件**　東のマントで裏見台に渡ったところで、窓の逆光が二つの模様を照らす。

**使う場面**　[M12 空席と欠け月の模様に、伏せた舟を合わせる](main-route.md#m12)

自動で手元に掛かる。ほかの場所で見た模様の写しでは帯の切り欠きを再現できない。

<a id="i09"></a>

### I09　伏せ舟の影板

**入手**　[M11 柱の低い位置にある二つの穴に備品図を重ねる](main-route.md#m11)

**隠し場所**　南の冬客間。王女の幼少期の背丈にある柱の内側。

**入手の条件**　西資料室の備品図の穴を柱に合わせて、薄板の押さえを外す。

**使う場面**　[M12 空席と欠け月の模様に、伏せた舟を合わせる](main-route.md#m12)

帯は別棟で得る。どちらを先に見つけても保管できる。

<a id="i10"></a>

### I10　王女の星暦頁

**入手**　[M12 空席と欠け月の模様に、伏せた舟を合わせる](main-route.md#m12)

**隠し場所**　北の星暦室。誰でも見る暦盤の冬至の窓の内側に挟まっている。

**入手の条件**　西の透かし帯と南の影板を重ねる。空席、欠け月、伏せた舟の向きが揃う。

**使う場面**　[M13 二羽の鳩が彫られた返書筒に星暦頁を通す](main-route.md#m13) ／ [M14 星暦頁と覗き錘を使い、肖像に隠された言葉を写す](main-route.md#m14)

頁の穴は東の返書筒の留めにも合う。使っても消えない。

<a id="i11"></a>

### I11　覗き錘

**入手**　[M13 二羽の鳩が彫られた返書筒に星暦頁を通す](main-route.md#m13)

**隠し場所**　東の鳩舎。本物の巣でなく二羽彫りの王女専用返書筒の奥。

**入手の条件**　星暦頁が筒の留めを外す。重心をずらした卵形で、底にレンズがある。

**使う場面**　[M14 星暦頁と覗き錘を使い、肖像に隠された言葉を写す](main-route.md#m14) ／ [M19 冠のない像の背にあるくぼみに覗き錘を置く](main-route.md#m19)

肖像を読んだ後は取り外して返る。王家の像に載せた時だけ設置済みになる。

<a id="i12"></a>

### I12　王女の私筆の控え

**入手**　[M14 星暦頁と覗き錘を使い、肖像に隠された言葉を写す](main-route.md#m14)

**隠し場所**　西の肖像修復室。顔料の下の文字は通常の光では断片しか出ない。

**入手の条件**　星暦頁を額に挟み、覗き錘を載せて、首輪の翻訳が残るうちに全図を自筆で写す。

**使う場面**　[M16 見張りの交代に合わせ、香車を返す予約を入れる](main-route.md#m16) ／ [M18 巡回環の切れ目が重なったら、白百合の壁際を渡る](main-route.md#m18) ／ [M19 冠のない像の背にあるくぼみに覗き錘を置く](main-route.md#m19)

翻訳が切れても自分の言葉と絵は読める。絵師に内容は伝えない。

<a id="i13"></a>

### I13　巡回環

**入手**　[M15 鐘番の当番盤から巡回環を借りる](main-route.md#m15)

**隠し場所**　南鐘番室。勤務盤で客の荷に貸し出す現行品。

**入手の条件**　鐘の音を覚えるだけでは予約できない。現行の欠け歯が香車に合う。

**使う場面**　[M16 見張りの交代に合わせ、香車を返す予約を入れる](main-route.md#m16) ／ [M18 巡回環の切れ目が重なったら、白百合の壁際を渡る](main-route.md#m18)

予約後に環は戻る。手元の切れ目で白礼拝廊の空番を読める。

## 任意の宝箱と中身

**[E009 通行章の片割れ](threads/T01.md#e009)**　[C05 衣装小部屋](castle.md#c05)。金色の章は通行証ではなく礼装の飾りだった。衣装箱へ戻し、同じ飾りが描かれた衣装の絵を受け取った。

**[E020 星糸の針箱](threads/T02.md#e020)**　[E04 衣装繕い室](castle.md#e04)。マントの裏地と同じ布の見本を受け取った。本物の箱は東廊下にあるようだ。

**[E033 割れ物の小箱](threads/T03.md#e033)**　[N08 標本廊](castle.md#n08)。二つの陶片のうち、作り手の署名が入ったほうを借りた。

**[E053 空の雨具箱](threads/T04.md#e053)**　[G05 庭師小屋](castle.md#g05)。救護札の窓と印を重ねる練習に使えそうな紙を手に入れた。

**[E065 香らない薬箱](threads/T05.md#e065)**　[N04 薬草乾燥室](castle.md#n04)。言葉が通じなくなっても目印にできる、薬草の絵札を手に入れた。

**[E079 逆さに開く小道具箱](threads/T06.md#e079)**　[E06 舞台倉](castle.md#e06)。物の裏側をのぞき見るのに使えそうな手鏡を借りた。

**[E095 布団の船着場](threads/T07.md#e095)**　[S02 冬客間](castle.md#s02)。玩具箱の引き戸から、名前の消えた乗客の人形を借りた。

**[E110 日陰で開く星箱](threads/T08.md#e110)**　[N06 天文露台](castle.md#n06)。星形の穴を写し取るための練習用の素通し板を手に入れた。

**[E126 豆一升の受取箱](threads/T09.md#e126)**　[E03 王家の鳩舎](castle.md#e03)。鳩を落ち着かせる小さな止め鈴を借りた。

**[E139 楮紙の封箱](threads/T10.md#e139)**　[W07 製本台の間](castle.md#w07)。光を当てて署名の違いを見比べられる、薄い裏打ち紙を手に入れた。

**[E155 検札の遺失物箱](threads/T11.md#e155)**　[S04 南門検札所](castle.md#s04)。落とし物の青い手袋を預かった。持ち主を探して返そう。

**[E171 端切れ型の粉箱](threads/T12.md#e171)**　[S07 パン窯室](castle.md#s07)。粉箱から七枚の名札が見つかった。かつて食卓を囲んだ七人の席を、もう一度整えられる。

**[E186 藁の下の石箱](threads/T13.md#e186)**　[B02 貯氷室](castle.md#b02)。石箱が開き、中から木べらの絵を取り出した。

**[E200 舌のない鈴箱](threads/T14.md#e200)**　[N05 鐘鋳場](castle.md#n05)。箱の中から、音が聞こえなくても振動で合図が伝わる手鈴を見つけた。

**[E217 剣先より軽い櫃](threads/T15.md#e217)**　[E06 舞台倉](castle.md#e06)。櫃の中にあったのは本物の剣ではなく、初演の入場券だった。

**[E228 書簡の重し箱](threads/T16.md#e228)**　[W07 製本台の間](castle.md#w07)。重し箱から、まだ封の切られていない手紙と白い糸の端を預かった。

**[E245 芽をつぶさない木箱](threads/T17.md#e245)**　[G07 回転温棚](castle.md#g07)。花を傷めずに運べる、吊り下げ式の鉢を借りた。

**[E261 旧番の道具箱](threads/T18.md#e261)**　[S03 鐘番室](castle.md#s03)。練習用の環を借りた。実際の予約に使う巡回環とは形が違う。

**[E281 無音の記念匣](threads/T19.md#e281)**　[Q01 無音祈祷室](castle.md#q01)。小箱の中には、揺らしても少しも音の立たない布の耳飾りが入っていた。

**[E288 王女の乳歯の匣](threads/T20.md#e288)**　[Q04 王家の抜け穴](castle.md#q04)。中の乳歯には触れず、箱の模様だけを銀紙に写し取った。
