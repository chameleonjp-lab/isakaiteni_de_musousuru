### E271　音を食べる壁

**手掛かり**　[Q01 無音祈祷室](../castle.md#q01)　主人公のみ・場所の反応

**成立に必要**　[M16](../main-route.md#m16)　 **時期**　謁見後、解除前　 **保存先**　手帳の記憶

**行動**　扉を開けたときと閉めたときに、指を鳴らして音を聞く

閉じると蝋燭の火だけが揺れ、隣室の鈴は揺れない。

**結果**　扉を閉めると音が外に伝わらない。ここなら首輪の留め金を外す音を隠せる。

**他の場面との関係**　示唆 → [M17 扉を閉じてから、白鍵で首輪を外す](../main-route.md#m17)

### E272　最後に読む言葉

**選択**　[Q01 無音祈祷室](../castle.md#q01)　主人公のみ・場所の反応

**成立に必要**　[M16](../main-route.md#m16)　 **時期**　謁見後、解除前　 **保存先**　その時点の世界

**行動**　王女の書き置きの「百合」か「境」を、手帳の表紙に写す

王女の書き置きには、百合と境石の絵がある。どちらを表紙に写しても、道順は手帳に残る。

**結果**　首輪を外したら、選んだ印のページから開こう。どちらの絵も手帳に残した。

**他の場面との関係**　余韻 → [E283 選んだ頁をひらく](#e283)


**この要素を参照する場面**　[E283](#e283)（成立条件） ／ [E283](#e283)（回収）

**選んだ結果**

<a id="e272-a"></a>

- **E272.A　百合を表紙に写す**　白百合の絵を開けば、歩いてきた道を見返せる。

<a id="e272-b"></a>

- **E272.B　境石の印を表紙に写す**　境石の絵を開けば、この先で探す目印を確かめられる。

**選択を反映する場面**　[E283](#e283)

### E285　外した輪をどう記すか

**選択**　[Q03 旧礼拝堂](../castle.md#q03)　主人公のみ・場所の反応

**成立に必要**　[M18](../main-route.md#m18)　 **時期**　解除後、境石を越えるまで　 **保存先**　その時点の世界

**行動**　首輪を「贈り物」として描くか、「命令」として描くか選ぶ

手帳にはまだ空白がある。外した首輪をどんな絵にするかは、自分で決められる。

**結果**　あの首輪が自分にとって何だったのか、手帳の最後に絵で残した。

**他の場面との関係**　余韻 → [E300 最後の頁は誰のもの](T20.md#e300)


**この要素を参照する場面**　[E300](T20.md#e300)（成立条件） ／ [E300](T20.md#e300)（回収）

**選んだ結果**

<a id="e285-a"></a>

- **E285.A　贈り物として描く**　手帳に留め金を描き、余白に自分の名を書いた。

<a id="e285-b"></a>

- **E285.B　命令として描く**　手帳に切れた鎖を描き、余白に自分の名を書いた。

**選択を反映する場面**　[E300](T20.md#e300)
