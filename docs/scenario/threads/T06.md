# T06　舞台で消えるもの

[資料の目次](../README.md) ・ [最短行程](../main-route.md) ・ [城内地図](../castle.md) ・ [人物](../cast.md)

隠密のマント、黒幕、舞台の影。どれが目をごまかし、どれが本当に姿を消すのかを確かめる。

### E076　影の落ちない衣装

**手掛かり**　[E06 舞台倉](../castle.md#e06)　[P14 舞台番トワ](../cast.md#p14)

**成立に必要**　[M02](../main-route.md#m02)　 **時期**　謁見後、解除前

**行動**　返却帳で「光にかけて乾かすな」の行を選ぶ。

星の印の下に「東廊下・木箱」。黒幕には普通の物干し印。

**結果**　星箱の場所をメモする。

### E077　消えた主演

### E087　降りやまない拍手

**選択**　[E08 小劇場](../castle.md#e08)　[P05 楽師ノノ](../cast.md#p05)

**成立に必要**　[E086](#e086)　 **時期**　謁見後、解除前
