### E151　門柱の作法絵

**手掛かり**　[S04 南門検札所](../castle.md#s04)　[P24 門番ウル](../cast.md#p24)

**成立に必要**　[M02](../main-route.md#m02)　 **時期**　謁見後、解除前　 **保存先**　手帳の記憶

**行動**　掲示板のめくれた角を持ち上げ、三枚の絵を見る

剝がれかけた紙の下から三枚の絵が現れた。右手、胸の二点、そして頭を下げる客。背景に描かれた門は、内側の格子戸だけだ。

**結果**　南門での正しい礼と、どこまで入ってよいかを示す作法絵を手帳に写した。

### E152　右胸に二度

**選択**　[S04 南門検札所](../castle.md#s04)　[P24 門番ウル](../cast.md#p24)

**成立に必要**　[E151](#e151) または [E014](T01.md#e014)　 **時期**　謁見後、解除前　 **保存先**　その時点の世界

**行動**　右胸を二度たたいて一礼するか、列を離れる

ウルは内格子の脇に立ち、あなたの礼を静かに待っている。その奥にある外の扉には、まだ太いかんぬきが掛かったままだ。

**結果**　右手で右胸を二度たたいて一礼すれば、内側の窓口で荷を調べてもらえる。列に戻れば、もう一度試せる。

**他の場面との関係**　反証 → [E154 町行きの空馬車](#e154)


**この要素を参照する場面**　[E007](T01.md#e007)（示唆） ／ [E014](T01.md#e014)（示唆） ／ [E151](#e151)（示唆） ／ [E159](#e159)（反証） ／ [E163](#e163)（示唆）

**選んだ結果**

<a id="e152-a"></a>

- **E152.A　右胸を二度たたいて一礼する**　内側の検札棚へ通され、荷を照会するための札を受け取った。


**この要素を参照する場面**　[E155](#e155)（成立条件） ／ [E159](#e159)（成立条件） ／ [E160](#e160)（成立条件）

<a id="e152-b"></a>

- **E152.B　一礼だけで列を離れる**　安全な待機線まで戻った。荷の照会は、もう一度並べば試せる。

**選択を反映する場面**　[E155](#e155)

### E163　礼を間違えた客

**選択**　[S04 南門検札所](../castle.md#s04)　[P24 門番ウル](../cast.md#p24)

**成立に必要**　[M02](../main-route.md#m02)　 **時期**　謁見後、解除前　 **保存先**　その時点の世界

**行動**　安全線の外で左手の礼を試すか、距離を取る

ウルが足元の安全線を指さした。「ここから先へ出なければ、礼は落ち着いて試せますよ」

**結果**　安全線の外なら五秒の警告は始まらない。並び直して何度でも礼を試せる。

**他の場面との関係**　示唆 → [E152 右胸に二度](#e152)


**選んだ結果**

<a id="e163-a"></a>

- **E163.A　安全線の外で左手を使う**　ウルは叱る代わりに、自分の右手で正しい礼のしかたを見せてくれた。

<a id="e163-b"></a>

- **E163.B　手を下ろして距離を取る**　砂灯は点かず、掲示板の作法を落ち着いて読み直せた。

### E165　鐘は外扉の合図か
