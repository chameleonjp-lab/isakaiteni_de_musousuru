### E151　門柱の作法絵

**手掛かり**　[S04 南門検札所](../castle.md#s04)　[P24 門番ウル](../cast.md#p24)

### E152　右胸に二度

**選択**　[S04 南門検札所](../castle.md#s04)　[P24 門番ウル](../cast.md#p24)

**成立に必要**　[E151](#e151) または [E014](T01.md#e014)　 **時期**　謁見後、解除前　 **保存先**　その時点の世界

**行動**　掲示を見て、右胸を二度たたいて一礼するか、一礼だけで列を離れる。

完全な礼なら番が内格子を引く。列を離れれば番も手を下ろす。どちらから見ても外扉の閂は動いていない。

**結果**　完全な礼をした時だけ検札棚で荷を照会できる。列に戻って礼を試し直せる。

**他の場面との関係**　反証 → [E154 町行きの空馬車](#e154)


**この要素を参照する場面**　[E007](T01.md#e007)（示唆） ／ [E014](T01.md#e014)（示唆） ／ [E151](#e151)（示唆） ／ [E159](#e159)（反証） ／ [E163](#e163)（示唆）

**選んだ結果**

<a id="e152-a"></a>

- **E152.A　右胸を二度たたいて一礼する**　内側の検札棚の受け札が出る。


**この要素を参照する場面**　[E155](#e155)（成立条件） ／ [E159](#e159)（成立条件） ／ [E160](#e160)（成立条件）

<a id="e152-b"></a>

- **E152.B　一礼だけで列を離れる**　外側の待機線へ戻る。荷の照会は次の訪問で試せる。

**選択を反映する場面**　[E155](#e155)

### E160　門が開いた噂の続き

**選択**　[C06 客人談話室](../castle.md#c06)　[P06 旅商ネウ](../cast.md#p06)

**成立に必要**　[E152.A](#e152-a)　 **時期**　謁見後、解除前　 **保存先**　その時点の世界

**行動**　「門が開いた」か「内格子が開いた」か、旅商に報告する。

「門が開いた」とだけ話すと番が訂正する。内格子と言えば旅商は門を二つ描く。以前、飾り章の訂正札を表に出していればその隣に、裏なら商人の手帳に書く。

**結果**　噂の文面と客の集まる場所が変わる。

**他の場面との関係**　照応 → [E010 旅商の訂正札](T01.md#e010)


**この要素を参照する場面**　[E010](T01.md#e010)（選択結果の反映元） ／ [E010](T01.md#e010)（照応）

**選んだ結果**

<a id="e160-a"></a>

- **E160.A　「門が開いた」と話す**　人が集まり、番が内格子と訂正する。

<a id="e160-b"></a>

- **E160.B　「内格子」と言い添える**　旅商が二重の門の図を掲げる。

**選択を反映する場面**　[E160](#e160)

### E163　礼を間違えた客

**選択**　[S04 南門検札所](../castle.md#s04)　[P24 門番ウル](../cast.md#p24)

**成立に必要**　[M02](../main-route.md#m02)　 **時期**　謁見後、解除前　 **保存先**　その時点の世界

**行動**　安全線の外であえて左手を使うか、手を下ろして距離を取る。

左手なら門番が自分の右手を上げて見せる。距離を取ると灯の砂が五粒とも上に戻る。

**結果**　礼をやり直せる。安全線の外では五秒の計測も始まらない。

**他の場面との関係**　示唆 → [E152 右胸に二度](#e152)


**選んだ結果**

<a id="e163-a"></a>

- **E163.A　安全線の外で左手を使う**　門番が右手で見本を示す。

<a id="e163-b"></a>

- **E163.B　手を下ろして距離を取る**　砂灯が灯らず、掲示板を落ち着いて読める。

**選択を反映する場面**　[E163](#e163)

### E165　鐘は外扉の合図か

**手掛かり**　[S03 鐘番室](../castle.md#s03)　[P23 鐘番ドル](../cast.md#p23)

**成立に必要**　[E161](#e161)　 **時期**　謁見後、解除前　 **保存先**　手帳の記憶

**行動**　門の小さな二音を鐘番に聞き比べてもらう。

「一音は受領、二音は点呼」。出門を告げる音は今は鳴っていない。

**結果**　当番の交代を調べる先が鐘番室だと分かる。
