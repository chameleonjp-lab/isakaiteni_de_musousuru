### E016　水面の燕

**手掛かり**　[E01 洗濯仕分け場](../castle.md#e01)　[P11 洗濯係ミナ](../cast.md#p11)

**成立に必要**　[M02](../main-route.md#m02)　 **時期**　謁見後、解除前　 **保存先**　手帳の記憶

**行動**　洗い桶の水面で干し台の裏を確かめる

波紋が静まった洗い桶の水面をのぞくと、上からはただの横棒に見えた影が、二股に分かれた燕の尾の形に映っていた。

**結果**　燕尾の布札が掛かっている高さを、地図に書き込んだ。

**他の場面との関係**　示唆 → [M04 図の印と同じ布札を、干し台の裏から取る](../main-route.md#m04)

### E017　切っていない二本糸

**ヒント**　[E04 衣装繕い室](../castle.md#e04)　[P12 針子リリ](../cast.md#p12)

**成立に必要**　[E016](#e016)　 **時期**　謁見後、解除前　 **保存先**　手帳の記憶

**行動**　燕の絵をリリに見せ、糸巻きと見比べる

リリが糸巻きを並べながら、明るく教えてくれた。「その二股の尾は千切れたんじゃないよ。戻す場所が二つあるっていう印なんだ」

**結果**　燕尾の布札は使っても手元に戻る。二か所で使えると手帳に書き留めた。

**他の場面との関係**　示唆 → [M06 布札と釉板を返納箱の左右の溝に合わせる](../main-route.md#m06) ／ 示唆 → [M09 燕尾の布札を東廊下の星箱の留め具に通す](../main-route.md#m09)

### E018　喪服と産着

**選択**　[E01 洗濯仕分け場](../castle.md#e01)　[P11 洗濯係ミナ](../cast.md#p11)

**成立に必要**　[M02](../main-route.md#m02)　 **時期**　謁見後、解除前　 **保存先**　その時点の世界

**行動**　二枚の白布の分け方を選ぶ

ミナが洗い台に二枚の白布を並べた。「パッと見はそっくりだろ？ 縫ってあるところもよく見てごらん」

**結果**　白布の見分け方を手帳に書き留めた。残った布はミナと一緒に仕分け直せる。

**他の場面との関係**　余韻 → [E019 小さすぎる夜着](#e019)


**この要素を参照する場面**　[E019](#e019)（成立条件）

**選んだ結果**

<a id="e018-a"></a>

- **E018.A　布の幅で分ける**　幅だけでは迷ったが、残った二枚はミナと一緒に見分け直せた。

<a id="e018-b"></a>

- **E018.B　縫い代の柔らかさで分ける**　柔らかな縫い代から産着のひもが見つかり、その場で迷わず仕分けられた。

### E029　裾の数え紐

**助け**　[E01 洗濯仕分け場](../castle.md#e01)　[P11 洗濯係ミナ](../cast.md#p11)

**成立に必要**　[E020](#e020) または [E028](#e028)　 **時期**　謁見後、解除前　 **保存先**　その時点の世界

**行動**　マントの内側に余り糸を結んでもらう
