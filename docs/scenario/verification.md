## 最短20行程を確かめた範囲

新規開始の状態で、まだ持っていない必須の印と、その時点で歩ける部屋の組み合わせを、行動数の少ない順にたどった。最初にクリアできるのは20行程。さらにM01からM20までを一つずつ禁止して探索すると、20通りのすべてでクリアできなくなった。任意300件で得られるのは各任意場面の状態・品・分岐値であり、主要な現物や王家の入口を代替する物は発行しない。

掲載順で歩く例は隣室への移動58回。仮の設計時計では、新しい操作20回×4分、移動58回×1分、交代を待つ余裕を最大12分として計150分以内。これはゲームの中の時間で、実際に遊ぶ所要時間は試遊で測る。

## 関係と失敗について確かめたこと

| 試したこと | 結果 |
| --- | --- |
| 300件の番号・題名・行動の重複、場所や人物、前提や参照の存在を調べる | E001からE300まで一件ずつあり、同じ題名・行動の重複なし。各場面を参照先から逆にたどれる。 |
| 一つの選択で同じ氷を二人に渡す、手紙を開けたうえで未開封として渡す | 両方の成立は不可。それぞれの枝から依頼の結びに到達できる。 |
| 首輪の解除前だけ可能な会話を終盤の前提に使う | 事前に実際に成立した情報や品は持ち込める。解除後に新たな訳や人との対面を要する場面はない。 |
| 13の重要品を手に入れる前に使う | 使用には入手元の行程が先に成立する。入手場所と各使用場所も異なる。 |
| 南門、馬車溜、像の前、暗渠、境石で、入室・観察・逆向き・正しい横断を試す | 魔道具の状態・目撃履歴・同じ逃走での入口通過を合わせた160通り中、成功するのは正しい組み合わせ1通り。 |
| 一度見つかった後に姿を隠し直す | 三回の観察に目撃が混じる7通りはすべて失敗。目撃なしの1通りだけ成功条件を維持する。 |
| 宝箱を含む任意場面を個別に開ける | 300件それぞれと明示した42組84個の選択値に成立する条件の組み合わせがある。排他的な結末は別々の試行で見る。 |

## 内容を読み直して直したところ

南門の一礼は荷の検札までとし、城外へ出る以前の試遊版の役割を改めた。受け札を使う後続場面には「実際に正しい礼をした」枝の条件を追加した。鍵を先に発見した場合は留め音を観察でき、無音祈祷室を探す根拠が残る。

秘密を守るため、王女の返書筒を鳩番が解説する場面を置かず、王家の抜け穴の脇棚も王族自身の絵具棚とした。解除後の廊下では通常のマントにも影が残る理由を、解除前の奉納灯で自分の目で試せる。

宝箱の条件は「場所さえ知れば開く」形から見直した。たとえば稽古用の手鏡を小劇場側で手に入れ、日時計庭で切れ目を読み、北の露台で両方を使って初めて星箱が開く。[鏡を得る](threads/T06.md#e079) ・ [影を読む](threads/T08.md#e109) ・ [露台の星箱](threads/T08.md#e110)

## 再確認する方法と資料の基準

リポジトリのルートで次を実行すると、最短行程、任意条件、選択の両立可否、地図、終端、文書内リンク、原本と読み物の一致を再確認できる。

```sh
python -B scripts/verify_scenario.py
```

今回確認したのは資料に記したルールの整合性。十秒で裏見台を渡る操作や視線の見え方、難しさ、実際の所要時間はゲーム実装後の試遊対象。試遊の基準は以前の会話にある「二度目で面を上げる」「翻訳の首輪と一日の刻限」「十秒のマント」「南門の作法」「死に戻り」。人物・場所・物品から場面、伏線から回収、条件から分岐へたどる構成は以前のシナリオ管理に合わせた。[シナリオ管理の資料とサンプル](https://github.com/chameleonjp-lab/shinariokanri/blob/main/docs/implementation/MANUALS_AND_SAMPLE.md)
