# 王都からの脱出　最短20行程

[資料の目次](README.md) ・ [最短行程](main-route.md) ・ [城内地図](castle.md) ・ [人物](cast.md)

異世界の城へ呼ばれた一般人は、王に贈られた翻訳の首輪を外し、城の敷地の外へ出る。王女は迎えに来ない。子供のころの玩具と、後年、肖像に残した言葉が主人公を外へ導く。

**行程の数え方**　新規開始から、プレイヤーが物語の状態を一段進める操作を一回と数える。移動、カメラ操作、メモの開閉、同じ操作で自動的に起きる結果は数えない。最初の二度の呼びかけは別々の選択。以下は最短の一例で、東の布札と北の釉板、医務の調査、王家の遺品、鐘番の調査には順序を入れ替えられる箇所がある。

**クリア判定**　首輪が外れている、解除以降に一度も目撃されていない、王家の入口を通った同じ逃走である、抜け穴の境石を内から外へ越えた。この四条件を同時に満たした時だけ成功する。謁見や解除前の通常の会話は可能。南門での一礼は内側の検札で完結する。

**場面を選ぶ**　[M01](#m01) ・ [M02](#m02) ・ [M03](#m03) ・ [M04](#m04) ・ [M05](#m05) ・ [M06](#m06) ・ [M07](#m07) ・ [M08](#m08) ・ [M09](#m09) ・ [M10](#m10) ・ [M11](#m11) ・ [M12](#m12) ・ [M13](#m13) ・ [M14](#m14) ・ [M15](#m15) ・ [M16](#m16) ・ [M17](#m17) ・ [M18](#m18) ・ [M19](#m19) ・ [M20](#m20)

### M19　冠なき像の背の空の巣に、覗き錘を戻す

**場所**　[Q03 旧礼拝堂](castle.md#q03)　 **相手・対象**　冠なき像　 **成立に必要**　[M13](#m13) ＋ [M14](#m14) ＋ [M18](#m18)

像が動く前に、祭壇の影だけが指一本ぶん伸びる。衣擦れのような音で床が下がり、王家の古い階段が現れる。

**変化**　王家の入口を通った印が立つ。階段も暗渠もまだ敷地内。入口を通るだけではクリアしない。

### M20　抜け穴の境石を越えて外の草を踏む

**場所**　[Q05 境石と外の草地](castle.md#q05)　 **相手・対象**　主人公　 **成立に必要**　[M17](#m17) ＋ [M18](#m18) ＋ [M19](#m19)

冠の刻みが背中側を向く。遠い城の鐘が鳴る。今度は誰の命令にも聞こえない。

**変化**　首輪が外れ、解除以来の発見がなく、王家の入口から連続して境界を内から外へ横切った時だけ脱出が成立する。
