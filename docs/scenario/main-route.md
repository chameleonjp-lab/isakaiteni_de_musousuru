# 王都からの脱出　最短20行程

異世界の城に呼ばれた一般人が、王に贈られた翻訳の首輪を外し、生きて敷地の外へ出る。王女は助けに来ない。子供のころの道具と、成長してから肖像に残した言葉が、主人公を外へ導く。

**数える単位**は、新しく始めた一周で、物語の状態を進めるプレイヤーの選択一回。歩行、カメラ、メモの開閉、自動で手に入る結果は数えない。王の二度の呼びかけには別々に答える。並びは成立する最短順の一例で、調度品、王家の遺品、交代の調査は途中で並行できる。

**唯一の出口**は王族だけが知る抜け穴。謁見や首輪をつけている間の日常会話は逃走の発見に含めない。解除の直後から敷地外に出るまで、姿を認められた瞬間にその試みが失敗する。一度追跡を振り切っても成功には戻らない。

<a id="M01"></a>

### M01　最初の「面を上げよ」で伏せて待つ

**場所**　C01　 **相手・対象**　国王　 **前提**　召喚直後

目の前には赤い絨毯だけ。隣の侍従の指もまだ床についている。先に顔を上げれば衛兵の槍の石突きが床を打つ。

**変化**　王がもう一度呼ぶ。王族の言葉には、言葉だけでは読めない間がある。

<a id="M02"></a>

### M02　二度目の呼びかけで顔を上げる

**場所**　C01　 **相手・対象**　国王・王女リゼ　 **前提**　[M01](#M01)

「客人に、我らの言葉を」。首輪がぬるくなり、音の上に意味が重なる。王女は首元を見て、笑うのをやめる。

**変化**　客人として居住区へ出られる。客札の絵は西の資料室、首輪の留め金の印は北の施療院を指す。

<a id="M03"></a>

### M03　客札で綴じ直した備品図を借りる

**場所**　W01　 **相手・対象**　司書ネリ　 **前提**　[M02](#M02)

西の棚で、紙の下から布と焼き物の印が半分ずつのぞく。余白には「対の見本は東の洗い場と北の窯へ」、南には「返納庫」とある。

**変化**　綴じ穴のある備品図を得る。壁と物の移転先を地図に写す。冬客間の欄に、移築前の「子供部屋」の線が残る。

<a id="M04"></a>

### M04　図の布印に合う燕尾の布札を、干し台の裏から引き出す

**場所**　E01　 **相手・対象**　洗濯係ミナ　 **前提**　[M03](#M03)

下げ札だらけの旧制服。布印にぴたりと合う一枚だけ、手の中で尾が二つに開く。裏に東廊下の星箱の焼き印がある。

**変化**　現物の「燕尾の布札」を得る。返納庫の左の溝と、東廊下の星箱の留め具に合う。使用後は手元に戻る。

<a id="M05"></a>

### M05　備品図の欠けた縁に合う釉薬見本を型から外す

**場所**　N01　 **相手・対象**　陶工イオ　 **前提**　[M03](#M03)

同じ青灰色の見本が並ぶ。縁が波形に欠けた一枚だけが合い、裏に三本の溝が走る。

**変化**　右半分の現物「三溝の釉板」を得る。布札と先にどちらを探してもよい。

<a id="M06"></a>

### M06　布札と釉板を合わせ、返納箱の受け口に差す

**場所**　S01　 **相手・対象**　仕掛け戸　 **前提**　[M04](#M04) ＋ [M05](#M05)

二片の間に一羽の水鳥が現れ、底板が手のひら一枚ぶん上がる。鍵の形をした物はない。

**変化**　雨量計を整備する「中空の調律棒」を取り出す。柄には中庭の鷺が刻まれている。

<a id="M07"></a>

### M07　首輪の印に合う救護札を記録棚から引く

**場所**　N02　 **相手・対象**　療術師セト　 **前提**　[M02](#M02)

「明日の同じ鐘で、この輪は命じられた身体を止められなくする」。救護札の透き窓に「雨仕舞い線・水鳥の左脚」の絵。

**変化**　刻限を知り、雨仕舞い線を合わせる透明な救護札を借りる。ここは備品図を探す前にも寄れる。

<a id="M08"></a>

### M08　救護札の窓が示す左脚の切れ目に調律棒を差す

**場所**　G01　 **相手・対象**　雨量計の鷺　 **前提**　[M06](#M06) ＋ [M07](#M07)

左脚の中で水が一滴落ちる。くちばしが開き、植木鉢に見えた受け皿へ小さな白い鍵が滑る。

**変化**　魔道具の「白鍵」を得る。庭にあるのは、水を閉じれば医務用の予備品を乾いた筒から返せる旧設備だから。

<a id="M09"></a>

### M09　燕尾の布札で東廊下の木箱の布留めをほどく

**場所**　E02　 **相手・対象**　星箱　 **前提**　[M04](#M04)

衣装の山の底で、星の裏地だけが視線からすっと消える。箱の蓋には「裏見台まで十秒」の繕い書き。

**変化**　隠密のマントを得る。一回の使用は10秒。安全な出発位置へ戻ると再び使える。

<a id="M10"></a>

### M10　マントを使って織物回廊の裏見台を渡る

**場所**　W02　 **相手・対象**　裏見台　 **前提**　[M09](#M09)

十の裾模様が順に光を失う。渡り切ると窓の逆光を浴び、表の祝宴にはなかった「空席、欠け月」が裏に並ぶ。端の帯が手に掛かる。

**変化**　王家の「透かし帯」を得る。星暦室の枠に通す現物。台での取得は通過時に自動で起きる。

<a id="M11"></a>

### M11　冬客間の背くらべ柱に、備品図の綴じ穴を重ねる

**場所**　S02　 **相手・対象**　幼い日の王女の痕跡　 **前提**　[M03](#M03)

子供の目の高さだけに、小舟を逆さに持った手が浮かぶ。図の綴じ穴から押さえを通すと、薄板が抜ける。

**変化**　「伏せ舟の影板」を得る。縁の星形が北の星暦室の枠と合う。

<a id="M12"></a>

### M12　透かし帯と影板を星暦盤の冬至の窓に重ねる

**場所**　N03　 **相手・対象**　王家の星暦盤　 **前提**　[M10](#M10) ＋ [M11](#M11)

空席の次に欠け月、その下で舟が伏せる向きだけ、王女の名と二羽の鳩が星穴に並ぶ。

**変化**　穴の列がある「王女の星暦頁」が外れる。鳩舎の返書筒と、肖像の裏打ち紙の星穴が描かれている。

<a id="M13"></a>

### M13　星暦頁の穴を、鳩舎の二羽彫りの筒の留めに通す

**場所**　E03　 **相手・対象**　王女の返書筒　 **前提**　[M12](#M12)

手紙は一枚もない。巣材の奥で、掌に重い真鍮の卵が転がる。底に小さなレンズがある。

**変化**　「覗き錘」を得る。レンズは西の肖像に、卵形の重さは旧礼拝堂の天秤に使える。

<a id="M14"></a>

### M14　星暦頁を挟んだ肖像の額に、覗き錘を座らせる

**場所**　W03　 **相手・対象**　王女リゼの私筆　 **前提**　[M12](#M12) ＋ [M13](#M13)

肖像の王女の目に字が映る。「白百合の縁、冠なき像の背。境の冠を振り返れば、あなたはもう客ではない」。裏面に卵を載せる手の図。

**変化**　白い廊下の図と秘密の抜け穴の入口・出口を、首輪が訳せるうちに自分の言葉と絵で控える。全経路を記したのは王女だけ。

<a id="M15"></a>

### M15　鐘番室の当番盤から、客用の巡回環を借りる

**場所**　S03　 **相手・対象**　鐘番ドル　 **前提**　[M02](#M02)

「客の荷を通すなら、歯の欠けた一刻に」。鐘番は人員配置の話だけをする。二本の切れ目の間だけ西番が交代する。

**変化**　時刻を指で読める「巡回環」を得る。切れ目が次に合う時は盤面にも出る。

<a id="M16"></a>

### M16　香支度室で、巡回環の空番に香車の返納を予約する

**場所**　W04　 **相手・対象**　点呼の香車　 **前提**　[M14](#M14) ＋ [M15](#M15)

控えの廊下で車輪が鳴り、西番は点呼へ向かう。香車が戸を押さえ、向こうの白百合が床に一列だけ見える。

**変化**　安全に首輪を外せる祈祷室と無人の交代時間を確保する。白鍵がまだなら、解除前は自由に戻って支度できる。予約は次の空番にも残る。

<a id="M17"></a>

### M17　扉を閉じた無音祈祷室で白鍵を回す

**場所**　Q01　 **相手・対象**　主人公　 **前提**　[M08](#M08) ＋ [M16](#M16)

かちり。隣の部屋の祈り声が、意味のない音の列に戻る。メモの自筆の文字だけは昨日と同じように読める。

**変化**　魔道具が外れ、翻訳と命令の効力が切れる。ここから発見を記録する。解除直前の安全な場面を保存する。

<a id="M18"></a>

### M18　空番の切れ目で、白百合が続く壁際を渡る

**場所**　Q02　 **相手・対象**　西番の足音　 **前提**　[M17](#M17)

中央の白床には詰所の火が映る。花弁の続く縁だけは暗い。衛兵の靴音が遠ざかり、奥の戸が揺れる。

**変化**　誰にも姿を認められず旧礼拝堂に着く。反対の白床で見つかった時はこの逃走の失敗になる。

<a id="M19"></a>

### M19　冠なき像の背の空の巣に、覗き錘を戻す

**場所**　Q03　 **相手・対象**　冠なき像　 **前提**　[M13](#M13) ＋ [M14](#M14) ＋ [M18](#M18)

像が動く前に、祭壇の影だけが指一本ぶん伸びる。衣擦れのような音で床が下がり、王家の古い階段が現れる。

**変化**　王家の入口を通った印が立つ。階段も暗渠もまだ敷地内。入口を通るだけではクリアしない。

<a id="M20"></a>

### M20　抜け穴の境石を越えて外の草を踏む

**場所**　Q05　 **相手・対象**　主人公　 **前提**　[M17](#M17) ＋ [M18](#M18) ＋ [M19](#M19)

冠の刻みが背中側を向く。遠い城の鐘が鳴る。今度は誰の命令にも聞こえない。

**変化**　首輪が外れ、解除以来の発見がなく、王家の入口から連続して境界を内から外へ横切った時だけ脱出が成立する。
