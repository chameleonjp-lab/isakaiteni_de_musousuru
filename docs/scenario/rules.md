# 状態と死に戻り

[資料の目次](README.md)

召喚直後から翻訳の首輪を着けている。翌日の召喚刻に王の命令への強制服従が始まる。解除後は現地語の生の音だけが聞こえ、異世界文字の新規翻訳も止まる。解除前に自分の言葉で書いたメモと図は読める。

## 一度の逃走として判定する

解除前は、客として会話し、物を借り、仕事を手伝える。閉じた無音祈祷室で白鍵を回すと、同じ逃走を表す印が始まる。姿を衛兵や城の人に認められた瞬間に発見が確定する。姿を再び消してもその試みには戻れない。私筆を読めるのは解除前。誰にも話さず自分で絵を控える。鳩番、絵師、鐘番が語るのは各自の持ち場だけ。

| 魔道具 | 解除以来の目撃 | 王家の通路 | 境界操作 | 結果 |
| --- | --- | --- | --- | --- |
| 外した | なし | 同じ逃走で入口を通過 | 境石の内から外へ | クリア |
| 装着中 | なし | 問わず | 問わず | 探索が続く |
| 外した | あり | 問わず | 問わず | 発見の時点で失敗 |
| 外した | なし | 未通過 | 南門・荷車・池など | 敷地内にとどまる |
| 外した | なし | 通過済み | 入口、暗渠、境石の内側 | 逃走が続く |

## 何を持ち越すか

死亡や発見で、選択・危険の直前の安全な位置へ戻す。そこまでに確定した物・装置・時刻・依頼の選択はその時点の状態に復元し、失敗した操作で消費した物も戻す。死因、調べた場所、重要な自筆メモは記憶として重ねる。目撃フラグだけを書き換えてその場で続行する操作は設けない。逃走中の再試行は、安全だった直前の位置・所持品・入口の通過状況をまとめて復元し、そこから行った試みとして判定する。解除前に任意場面を探し直せるよう祈祷室には解除直前の記録も残す。

資料のE番号は任意場面を特定する番号。前提が「E番号」の場合、手掛かりや死因は記憶、現物・依頼は現在の世界で得た状態を使う。宝箱や道具の現物は同じ一周で二重に発行しない。通常の失敗で主要道具はなくならず、正解を知っていても現物・仕掛けの状態を飛ばせない。

## 時間と危険

追加案ではゲーム内の一日は1,440分。準備中の新しい調査・仕事は原則4分、隣の部屋への移動は1分。メモや地図を読む間、選択肢を読んでいる間、画面を閉じている間は止まる。刻限直前には前の安全記録を保持し、再開のたびに同じ時刻で詰まる状態を避ける。十秒のマントと南門前での五秒の滞留はそれぞれ危険区間内の演出時間で、図形の減り方も併記する。空番は遅くともゲーム内12分で巡る。予約後は次の空番を選んでその時刻へ進められ、現実の待機を求めない。首輪を外すと翌日の強制は消える。

マントは衣装として見える姿を十秒間隠す。禁域の立入線、門の可否、魔法の作動条件、すでに成立した発見は変えない。最終区間は王家の礼拝区の奉納灯が全身の影を床に写すため、マントにも影が出る。この性質は解除前から灯と衣装の見本で確認できる。中央の白床を歩けば発見、百合の縁を空番に選んだ時だけ未発見で渡れる。

## 旗の読み方と選び直し

M01〜M20は、それぞれの必須操作が現在の世界で成立した印。任意場面を読んでもMの印は立たない。E001〜E300は一つずつ独立した任意場面で、発見失敗や死に戻りを体験した場合も、その記憶を手帳に載せる。場面の「保存先」が「その時点の世界」の場合は、死に戻る先で持っていた道具や当時の選択と一緒に戻す。後から図鑑で見た結末から現物は発行しない。

番号の後ろの「.A」「.B」は、その場面で実際に選んだ方を表す。たとえば「E185.A ＋ E191」は、氷を病室へ送ると決め、運搬用の器も用意した時に開く。「または」で並んだ条件はどちらか片方でよい。氷の一片、私信の開封、花の見せ方などは一周につき一方の選択を残し、別の結果は選ぶ前の記録で試せる。礼法の練習（E005）、南門の検札（E152）、左右の紙の練習（E054）など実演はやり直せる。習得済みの礼と、既に出た受け札は保持する。

「示唆」「ヒント」は行き先の手掛かり、「補助」は表示や練習で助ける関係。「予告」「回収」「余韻」は前に仕込んだ物と後で返る結果を結び、「反証」は噂とそれを確かめられる場面の組、「照応」「対照」は意味や見え方を比べるための参照を示す。成立に必要な条件は各場面の専用欄に載せた。関係をすべてたどらなくてもクリアできる。

## 間違えたときに残る根拠

| 先回りして試した行動 | その場で観察できること | 調べ直す先 |
| --- | --- | --- |
| 備品図を借りる前に布札や釉板を取る | 係が持ち出し用の対照図を求める。部屋の見学はできる。 | 西資料室の客用貸出棚 |
| 南の返納箱に片側の札だけを差す | 底が傾き、水鳥の半身しか揃わない。札は戻る。 | 空いた側の布目か釉の溝 |
| 鷺の隠し場所を知っていて棒だけを差す | 救護札の厚みがなく、棒が支えを失い、閉水位置に届かない。 | 首輪の医務印と北の救護札 |
| 鍵を取ったその場で首輪を外そうとする | 試しに鍵を当てただけで留め金が声のように鳴る。主人公は手を止め「音の漏れない部屋なら」と書く。 | 無音祈祷室の印と香車の支度 |
| 私筆の文言だけを暗記して像を調べる | 錘のない巣では床の天秤が動かない。 | 東の鳩舎の王女の返書筒 |
| 抜け穴の入口に立つ、南門で礼をする、境石の手前に立つ | 土と冠の向きがまだ城内。南門で開くのは検札の内格子だけ。 | 王家の通路を通った先の境石 |

解除前でも、立入禁止区域で侵入を見られた場合はその場で失敗する。許された場所での謁見・会話・依頼を進めたことは、脱出時の発見には数えない。

## 資料の更新

python -B scripts/scenario_atlas.py
