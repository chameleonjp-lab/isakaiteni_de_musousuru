# 状態と死に戻り

[資料の目次](README.md)

召喚直後から翻訳の首輪を着けている。翌日の召喚刻に王の命令への強制服従が始まる。解除後は現地語の生の音だけが聞こえ、異世界文字の新規翻訳も止まる。解除前に自分の言葉で書いたメモと図は読める。

## 一度の逃走として判定する

解除前は、客として会話し、物を借り、仕事を手伝える。閉じた無音祈祷室で白鍵を回すと、同じ逃走を表す印が始まる。姿を衛兵や城の人に認められた瞬間に発見が確定する。姿を再び消してもその試みには戻れない。私筆を読めるのは解除前。誰にも話さず自分で絵を控える。鳩番、絵師、鐘番が語るのは各自の持ち場だけ。

## 何を持ち越すか

死亡や発見で、選択・危険の直前の安全な位置へ戻す。そこまでに確定した物・装置・時刻・依頼の選択はその時点の状態に復元し、失敗した操作で消費した物も戻す。死因、調べた場所、重要な自筆メモは記憶として重ねる。目撃フラグだけを書き換えてその場で続行する操作は設けない。逃走中の再試行は、安全だった直前の位置・所持品・入口の通過状況をまとめて復元し、そこから行った試みとして判定する。解除前に任意場面を探し直せるよう祈祷室には解除直前の記録も残す。

資料のE番号は任意場面を特定する番号。前提が「E番号」の場合、手掛かりや死因は記憶、現物・依頼は現在の世界で得た状態を使う。宝箱や道具の現物は同じ一周で二重に発行しない。通常の失敗で主要道具はなくならず、正解を知っていても現物・仕掛けの状態を飛ばせない。

## 時間と危険

追加案ではゲーム内の一日は1,440分。準備中の新しい調査・仕事は原則4分、隣の部屋への移動は1分。メモや地図を読む間、選択肢を読んでいる間、画面を閉じている間は止まる。刻限直前には前の安全記録を保持し、再開のたびに同じ時刻で詰まる状態を避ける。十秒のマントと南門前での五秒の滞留はそれぞれ危険区間内の演出時間で、図形の減り方も併記する。首輪を外すと翌日の強制は消える。

マントは衣装として見える姿を十秒間隠す。禁域の立入線、門の可否、魔法の作動条件、すでに成立した発見は変えない。最終区間は王家の礼拝区の奉納灯が全身の影を床に写すため、マントにも影が出る。この性質は解除前から灯と衣装の見本で確認できる。中央の白床を歩けば発見、百合の縁を空番に選んだ時だけ未発見で渡れる。
