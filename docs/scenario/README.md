# 王都からの脱出　作者用シナリオ

王女が幼いころに遊んだ舟と、大人になってから描かせた肖像。呼び出された客人がこの二つを結んだとき、王の贈り物だった翻訳の首輪を外して帰る道が見える。

[最短20行程](main-route.md) ・ [城内地図](castle.md) ・ [人物と知っていること](cast.md) ・ [状態と死に戻り](rules.md)

任意の場面は一件ごとに成立条件、行動、台詞または演出、結果、前後の関係を記録する。各場面から地図・人物・関連する別の場面に移動できる。
